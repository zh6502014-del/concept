## 開啟

解壓縮後用瀏覽器開啟根目錄的 `index.html`。**不要只移動 index.html**，必須保留 `css/`、`js/` 與 `assets/` 的相對位置。本作品沒有 npm 安裝、編譯、CDN、帳號登入或後端需求。若本機檔案模式不允許儲存進度或複製信箱，介面提供降級回饋，仍可操作。

## V0.3 翻頁動畫

點擊前後翻頁按鈕、正文中的換頁按鈕、四章目錄，或使用鍵盤左右鍵，就會觸發翻頁。角色、線索、選牌、路塊與拼圖仍在當頁更新，不觸發整頁動畫。

- 桌機（寬度 > 680px）：沿中央書脊，右頁往左翻；上一頁反向。頁面正反面使用目前的實際內容，有書脊與漸變投影。
- 手機（寬度 ≤ 680px）：使用整張單頁翻開，不把內容硬切成兩半。
- 動畫時間：桌機 820ms、手機 680ms。圖片尚未就緒時最多額外等待 200ms；動畫不是等待圖片載入的強制關卡。
- 翻頁期間不接受連點或當頁操作；完成後恢復標題焦點。按 Escape 可立即完成。
- 寬度改變或分頁隱藏時，立即完成，避免停在半頁。手機網址列造成的單純高度變化不會打斷翻頁。
- 閱讀設定或系統啟用「減少動態」時，直接換頁。缺少動畫 API 時也能繼續閱讀。

延續 V0.2 的等寬外框、15 頁、四章內容、第 14 頁聯絡資訊、素材與本機儲存格式。沒有修改正式遊戲，也沒有重新生成圖片。

動畫獨立放在 `js/page-turn.js`、`css/page-turn.css`；`index.html` 依序載入它們，`app.js` 在換頁時呼叫。修改速度請調整 `page-turn.js` 頂端的 `OPTIONS`。注意保留 `index.html` 新增的載入行，不能只覆蓋 `app.js`。

## 修改方式

- 改署名／信箱／作品集網址：`js/content.js` 的 `AUTHOR`。
- 改世界設定／人物介紹／主題：同檔的 `WORLD`、`CHARACTERS`、`THEMES`。
- 換圖片：保持素材檔名與尺寸即可；改名時同時更新 `ASSETS`、`css/artwork.css` 及素材清單。
- 改書頁外框：`css/artwork.css` 的 `--book-max`，目前為 **1240px，包含外側 padding**。寬桌機的實際書頁外框為 1180px。所有頁面一致；手機按可用寬度縮放。**不把單頁再次限成較窄外框。**
- 單頁內文：最大 658px，與整本外框分開控制。書本依視窗設定固定高度；長內容在書頁內捲動，所有頁面維持相同外框高度。
- 故事規則：`app.js` 的 renderRules 為說明；`story-training.js` 使用 `vendor/story-energy-engine.js` 結算。自由對戰只出現在模式差異表。
- 驗證教學：`node tests/story-training.cjs`。原 Game_claude 不會被修改。
